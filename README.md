<h1>Selenium + RestAssured E2E Test Automation Project</h1>
<h2>Overview</h2>
<p>This project is an E2E test automation framework built in Java, combining Selenium WebDriver for UI testing and RestAssured for API interactions. The primary goal is to provide a scalable, maintainable test solution capable of ensuring the demo HR Management application is working as expected.</p>
<p>The framework is currently in progress, with new tests, features, and improvements added on a regular basis.
<h2>Key Technologies</h2>
<ul>
    <li>Java</li>
    <li>Selenium WebDriver</li>
    <li>RestAssured</li>
    <li>Maven</li>
    <li>TestNG</li>
</ul>
<h2>Main Features</h2>
<ul>
    <li>End‑to‑End Testing</li>
    <li>Page Object Model (POM)</li>
    <li>API‑Driven Test Data Management</li>
</ul>
<h2>Current Status</h2>
<p>This project is actively being developed. New tests and enhancements are added regularly.</p>
<p>Planned additions include:</p>
<ul>
    <li>CI/CD configuration</li>
    <li>More comprehensive UI test coverage</li>
    <li>Test reporting</li>
</ul>
